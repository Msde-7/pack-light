          How the pack works

          Every file Claude reads and every tool it runs lands in the pack as an item. The fuller the context window, the slower the hiker walks.

          When the window fills up, Claude Code compacts it. That is camp. Unpinned items stay behind in Lost & Found. Pinned items come back right after camp.

          Weights

          • Pebble, under ≈500 tokens
          • Book, under ≈2K
          • Brick, under ≈8K
          • Anvil, ≈8K and up

          Keys

          • ←→↑↓ move through the inventory
          • Enter opens an item
          • P pins or unpins it
          • Esc skips camp or closes the item
          • ? opens this help

          Numbers

          Item sizes are estimates, so they carry a ≈. Stamina counts toward the point where auto compaction starts, and the window share shows the raw context window.
